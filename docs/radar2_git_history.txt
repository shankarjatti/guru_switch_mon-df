    the code so they are not repeated:

         the real measurement, cried NO SIGNAL on channels tracking to 2 deg

         ch0 cancels the common error

         noise floor. Offline that case gives -35 dB

         immune to both, gives +26 dB on that same case and ~0 dB on a
         genuinely empty channel
